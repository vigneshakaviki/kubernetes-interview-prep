# Contributing

Thanks for adding real questions. Keep the bank trustworthy and legal.

## Rules

1. **Write original answers.** Never paste text from another site. Explain the concept
   in your own words. Facts (what's asked, how a thing works) aren't copyrightable —
   the expression is, so write your own.
2. **Questions must be real.** Base them on what's actually asked in interviews, not
   invented trivia.
3. **Answer in depth.** Lead with the core idea, then the *why*, the trade-offs,
   and the gotcha. One to three paragraphs — deep, not padded.
4. **Use the [TEMPLATE.md](./TEMPLATE.md) block.** One block per question, tagged with
   **Difficulty** and **Tags**.
5. **Put it in the right file** under `questions/`. If none fits, open an issue first.

## Style

- Lead with the answer, then the reasoning and trade-offs.
- Name the exact command / resource / failure mode.
- Call out the mistake a junior makes.
- No marketing, no fluff, no copied text.

## What gets rejected

- Verbatim copies of another site's text.
- Shallow textbook definitions with no reasoning or trade-offs.
- Invented questions nobody asks.
